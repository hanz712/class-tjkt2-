# Update Fitur Siswa - XI TJKT 2

Update ini mempertahankan desain utama project dan menambahkan:

- Pengaturan akun siswa: ganti password dan foto profil.
- Notifikasi jumlah pengumuman baru.
- Inbox pengumuman dengan status sudah/belum dibaca.
- Chat kelas langsung di dashboard + halaman chat lengkap.
- Riwayat chat tersimpan di MySQL.

## Untuk database yang sudah berjalan

Jalankan **database/fitur_siswa.sql** satu kali di phpMyAdmin.

## Untuk instalasi database baru

`database/database.sql` sudah berisi tabel fitur tambahan.

## Catatan

Akun siswa tetap dibuat melalui menu Data Siswa milik Wali Kelas. Username siswa mengikuti NIS seperti sistem sebelumnya.
