# XI TJKT 2 — Frontend

Frontend awal Portal Kelas XI TJKT 2.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `XI-TJKT2-Frontend` di VS Code.
3. Buka `index.html` dengan Live Server, atau buka langsung di browser.

## Isi
- Dashboard
- Daftar 36 siswa (data demo)
- Jadwal pelajaran
- Jadwal piket
- Halaman absensi QR (placeholder frontend)
- Tugas guru
- Galeri
- Informasi wali kelas
- Responsive mobile

## Catatan
Ini baru FRONTEND. Data siswa, login, QR scanner, absensi, CRUD, kalender, dan penyimpanan database akan disambungkan pada tahap backend PHP + MySQL.
