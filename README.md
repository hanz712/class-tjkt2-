# XI TJKT 2 — Portal Kelas

Frontend awal Portal Kelas XI TJKT 2 yang dibuat untuk menjadi pusat informasi dan aktivitas kelas dalam satu website.

## ✨ Fitur

### 🏠 Dashboard
Menampilkan informasi utama kelas secara ringkas, seperti data siswa, jadwal, piket, dan informasi kelas.

### 👨‍🎓 Data Siswa
Menampilkan daftar 36 siswa XI TJKT 2 dengan tampilan yang rapi dan responsif.

### 📚 Jadwal Pelajaran
Menampilkan jadwal pelajaran kelas agar siswa dapat melihat kegiatan pembelajaran dengan mudah.

### 🧹 Jadwal Piket
Menampilkan jadwal piket siswa berdasarkan pembagian kelompok atau hari.

### 📱 Absensi QR
Halaman absensi menggunakan QR Code sebagai rancangan awal sistem absensi digital.

### 📝 Tugas Guru
Halaman untuk menampilkan informasi dan daftar tugas yang diberikan oleh guru.

### 🖼️ Galeri
Menampilkan dokumentasi dan foto kegiatan kelas.

### 👩‍🏫 Informasi Wali Kelas
Menampilkan informasi wali kelas dan data yang berkaitan dengan kelas.

### 📱 Responsive Design
Tampilan dibuat responsive sehingga dapat digunakan melalui HP maupun komputer.

## 🛠️ Teknologi

- PHP
- HTML
- CSS
- JavaScript
- Bootstrap
- Font Awesome

## 📂 Struktur

Project ini menggunakan `index.php` sebagai halaman utama dan dirancang untuk dikembangkan menjadi sistem portal kelas dengan backend PHP + MySQL.

## 🚧 Status Project

**Frontend — Development**

Versi ini merupakan tahap awal frontend. Fitur seperti login, database, CRUD, QR scanner, absensi real-time, kalender, dan pengelolaan data akan dikembangkan pada tahap backend.
